## 下面是相较于原卡的改动
## 1. 新增：
- 顶栏增加当前 **年、月、日、星期** 的显示，时间显示更完全。
- 新增玩家身份获取途径，现在玩家的身份可以由后续剧情发展自动获取添加，理论上可无限加身份。||直接说也是可以的，说“我是傻逼”就真的可以获得傻逼身份（真的会有人这么说吗）||
- 新增 **宿舍** 变量，完善了宿舍相关的世界书设定，具体宿舍信息可在 **首页**（玩家）和 **角色详情页**（角色）中查看。
- 给玩家和角色都添加了 **违规记录** 变量，并完善了相关的违规后果，现在对应的违规记录可以在 **首页**（玩家）和 **角色详情页**（角色）的违规记录下拉菜单中查看。
- 违规记录到时间会自动清除，不依赖 AI 返回。||（游戏内 30 天，不知道有没有能玩到这么久的）||
- 角色详情页增加 **当前着装状态** 变量，与 **今日穿搭** 进行区分，今日穿搭用于整体，不大换装不改变；当前着装状态用于体现临时状态变化，如衣服被水泼湿之类的。
- 角色档案页的好感度进度条新增更多的阶段，用了更多的颜色种类区分。
- 角色详情页里新增好感度进度条，方便在详情页中查看好感度数值。
- 针对角色全知问题，新增 **圣樱自研AI管理系统** 作为校规管理、建筑管理、活动管理的 **中转站**，将原本的 **“校规管理APP”** 更名为 **“桜序”**。
- 建筑新增 **“施工状态”**，建筑不再是秒建秒拆，会随机生成 1~3 天的整改时间，时间一到即可自动 建成/拆除，具体的完工时间可点击建筑查看详情（具体时间靠 AI 随机返回的，一改完就看是看不到具体时间的）。
- 在 `item_作息时间表` 中增加了课表和社团，到点应该会自动抽取一门课来上。||不想上课的叫 AI 跳过即可||
- 新增 `item_创作要求` 世界书条目，用于抑制可能出现的“类型词标签词滥用、OOC、极端感受”等情况。
- 针对角色媚 user 问题，新增 `item_角色好感度阶段与行为指导建议` 世界书条目，用于限制发展速度与好感度相关的行为。||主要是测试模型是哈基米 3.1p，跟一个角色做过一次后，其他角色也动不动就发情。想猛猛推的可以把这个条目改改，不建议关掉，**硬要关的话就得同步把 `[mvu_update]变量更新规则` 里角色好感度中的本词条引用和 `item_创作要求` 中的本词条引用删掉**||

## 2. 调整：
- 调整了 **性格标签** 和 **性癖标签** 的初始词数。
- 角色详情页的原 **经验次数** 拆分成 **高潮次数** 和 **内射次数**，并增加了随机的初始数值。||可能会遇到 **黄金矿工** 学姐、**超绝性冷淡** 的 sensei 或 **外冷内齁** 的同学||
- 调整了地图编辑时建筑物跳动的幅度，现在长按地图建筑选中时的跳动幅度会变小，更好看清建筑的落点。
- 活动开启和结束时间精确到环节时间（即 第一个环节的开始和最后一个环节的结束），同时地图中的高亮显示也会精确到分钟。
- 调整了玩家开场时的初始身份，削弱了性别指向性。||（不然容易走极端）||
- 角色身份的上限调整到了 3 个，同时在后续剧情中发生角色身份变更事件时，角色身份的变量也会同步改变。||大概？只要 AI 注意得到应该都会更新的||
- 角色详情页下拉后，原本的 **姓名、班级、年龄、身份、宿舍** 的信息会挪动到头像旁边显示，不再隐藏。
- 调整了校规管理、建筑管理、活动管理时发送的内容，以适配系统更改。
- 调整了建筑拆除的逻辑，现在拆除后的建筑会直接清除该建筑的变量，不会再占用 MVU 变量列表的位置。

## 3. 修复：
- 修复了在特定情况操作下，前端会在活动结束前关闭活动相关世界书条目的 bug，现在就算是发消息之前手动禁用||（不是删除啊）||，只要活动还没结束，对应活动的世界书条目都会自动重新打开。
